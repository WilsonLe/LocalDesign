# LocalDesign

A browser-local design editor for people and external agents, using LocalCut’s shadcn/Base UI components, neutral theme and monochrome line-art branding. Draw on a canvas, organize layers, edit typography and layout, and export an editable `.localdesign` file, SVG, PNG, JPEG or PDF. No account, backend, model provider or runtime credentials.

**Try it:** https://wilsonle.github.io/LocalDesign/

**Plan:** [issue #1](https://github.com/WilsonLe/LocalDesign/issues/1)

## Use the editor

The root URL opens your browser-local workspace list. Create a blank design, open a saved workspace or import a file to enter `/LocalDesign/workspace/<document-id>`. Reloading that URL opens the same saved design; use the LocalDesign mark or workspace button to save and return to the list. Back and Forward navigate between the list and designs. Links only identify working copies in this browser; export a `.localdesign` file to move a design to another browser or device.

Start a new design with a blank dotted canvas that follows the app’s light or dark theme. Use the moon/sun button to switch themes; light is the default and your preference is saved in this browser. Explicit page background colors stay saved; Use app theme restores the theme-following surface. Theme changes do not recolor artwork or exported files. Choose Frame (F), Rectangle (R), Ellipse (O), Line (L), Path (P), Text (T) or Image (I). Drag to draw/move, use corner handles to resize and the round handle to rotate (Shift snaps to 15°). Shapes snap to a 4 px grid; Alt disables it. The inspector exposes exact position, size, rotation, appearance, text and frame auto layout. Layers display siblings in canvas reading order (top-to-bottom, then left-to-right; stable ties), independently of paint/layout order. Activate a layer name to select and center its world bounds, preserving zoom unless it needs to shrink to fit clear of floating controls; narrow layouts close the Layers drawer. Hidden/clipped content stays hidden/clipped. Shift activation retains multiselection. Large canvases render the visible area with a small margin while keeping offscreen layers editable and exports complete. Large layer lists render the visible rows; use search, scroll, or Up/Down/Home/End on a layer name to reach other rows. Layers support multiselection (Shift), visibility, lock, grouping, ordering, duplication, alignment and distribution. Frame layout uses padding, gap and cross-axis alignment; clipping is optional.

Space-drag or Hand (H) pans; ⌘/Ctrl-scroll zooms. `1` fits the page, `2` fits selection, `0` resets zoom. ⌘/Ctrl Z undoes; Shift Z redoes; D duplicates; G groups (Shift G ungroups); C/X/V copies/cuts/pastes; arrows nudge (Shift moves 10 px). Input fields keep their own normal typing/shortcuts. Pages and Layers scroll independently, keeping layer search and navigation reachable in documents with many pages. Narrow screens expose Pages & layers and Properties drawers. Help lists shortcuts and the complete bundled guides.

The workspace list opens/creates/manages browser-local documents, including deleting a closed workspace after confirmation. Cancel or Escape keeps it; a failed deletion offers a retry. IndexedDB saves working copies; storage errors expose retry, save-a-copy and portable backup actions. Export `.localdesign` to keep a backup or move to another device. Native/SVG/raster imports validate before opening as a separate local document, preserving the old working copy. Use Image to add a raster asset to the current design. Unsupported SVG constructs reject with an error; use a flattened PNG where appropriate.

Export options control scale, background and JPEG quality. Selected layers export in isolation by default; Include surrounding artwork crops the original composition around them, retaining overlaps and ancestor clips. JPEG composites transparency on white. PDF can contain 1–100 explicitly ordered frames from any document page. Ordinary PDF pages retain vector outlines; pages with group opacity use the shared PNG renderer at the chosen scale and report a warning to preserve exact compositing. Outputs are limited to 16,384 pixels per axis and raster output to 40 million pixels. Native export always keeps the complete editable document.

Design resources holds named guidelines, decisions and pinned selection snapshots, page ordering/moves, and typed design tokens with aliases, property bindings and themes. These remain browser-local and travel in the native file. Directly editing a bound property detaches that binding; deleting a used token requires an explicit detach action.

The Icons tab searches 48 bundled Lucide icons by name or keyword, previews their native geometry and inserts editable paths into the selected frame/group or current page. Choose size, weight and color before insertion. Icon paths scale with their bounds; the inspector also exposes their coordinate box, line caps/joins and attribution. Native files preserve complete notices; SVG/PNG/JPEG/PDF outputs embed deduplicated notices without changing the painted design. No remote icon service is used.

Components capture native frame/group selections, expose typed properties/variants and insert linked instances. Ordinary text/style edits become sparse overrides; reset or detach through Properties. Edit source copies with the existing editor, then review the affected-instance/conflict preview before publishing. Deleted definitions remain recoverable; direct uses freeze unless explicitly detached. Variant previews use the shared renderer.

History stores named frame/component checkpoints with dependency versions and licensed resources. Restore as a new revision: choose frozen frame artwork or explicitly restore changed linked dependencies after reviewing the diff. Retention is bounded to 100 checkpoints / 16 MB compact snapshot metadata / 100,000 stored parts, within the existing file budget; nothing is silently evicted. Portable `.localcomponents` files carry nested definitions, aliases/modes, images and actual font bytes. Packages imports explicitly selected versions into one document; updates keep stable links and require decisions about local edits and override conflicts. Removed source resources stay local. Clipboard paste uses the same dependency-aware owner.

Review holds anchored threads, replies and resolution, retaining last known context for missing anchors. Agent status is a visible expiring label, separate from document/history. Prototype holds native click navigation, back and overlays; choose an entry frame and play it locally with the shared renderer. Broken targets remain visible for repair. It executes no imported scripts.

Handoff requests await a human review action. Approval binds the frame's content and dependency versions, keeps a checkpoint and records trust separately in this browser. Content changes invalidate sign-off; imported or history-recreated claims require fresh review. Agent tools can request/read/revoke, and cannot grant approval. Actor/reviewer labels are user data; the UI boundary does not prove physical identity against a caller with full browser script/UI control.

### Connect an agent

LocalDesign exposes its agent tools through WebMCP. Use the agent host’s built-in browser first and discover this page’s tools before opening Chrome. Respect an explicit browser choice or an already attached LocalDesign tab; use another browser when the built-in browser is unavailable or lacks the required capability, and explain the observed reason. Open the same URL in that WebMCP-capable agent browser. Ask it to discover this page's tools, call `localdesign_list_skills`, and read `getting-started` with `localdesign_get_skill`. It edits the same document/history as you. Browser hosts may suffix canonical tool names: use the discovered names. The Connect agent dialog reports availability. [Connection and parity guide](docs/webmcp.md).

Three self-contained static instruction packages ship with the app: getting-started, UI design/critique and typography. They include complete operational guidance and attribution, need no Agentic Workflows installation or runtime GitHub fetch, and remain readable offline after the app loads. Design content deliberately returned to an external agent is handled by that agent/provider; LocalDesign itself does not upload it.

### v0.3 limits

Native `.fig`, variable fonts/font collections/color fonts, arbitrary SVG CSS/gradients/filters, vector booleans, advanced constraints, multiplayer and animation are outside this release. The narrow safe SVG importer is not a general SVG round-trip engine. Native archives preserve the complete editable scene; use them for lossless LocalDesign editing. Legacy paths retain literal coordinates on resize. Paths with a native coordinate box, including icons, scale with their bounds; weight remains consistent for uniform resizing. One document supports 100,000 nodes, 1,000 pages and 10,000 image assets. These are resource ceilings rather than format restrictions. Supported native designs stay within 64 MB UTF-8 metadata and a 120 MB combined metadata/image/local-font budget plus a 1 MB bundled-font reserve, so a successful native export fits the importer. Embedded raster images must decode and match their catalog dimensions. Inter and Source Serif 4 (400/600/700) and IBM Plex Mono (400/700), normal/italic, are bundled for Latin/extended Latin/Vietnamese. Use Typography’s family/weight/style controls and Fonts for previews, missing-font status and licensed static TTF/OTF/WOFF/WOFF2 files (4 MB/file, 48 local faces/12 MB/document). Font source distinguishes bundled and imported faces, including files sharing a family/weight/style. Missing requests remain inspectable; Replacement maps a face without changing the original request or text geometry. Glyph fallback warns separately from overflow. Canvas, SVG and PNG share glyph outlines and metrics; SVG text is outlined, while native text stays editable. Native schema v3 embeds fonts, permission/provenance, document context, tokens/themes, reusable definitions, checkpoints, review and prototypes; existing v1/v2 files still open. Older releases cannot read v3 files. System fonts are never read or redistributed; exact matching requires the licensed font bytes. Browser working copies remain origin/device-local. Undo/redo and retry receipts are memory-only and reset on reload/switch; named checkpoints and review records persist. Export before clearing browser data.

## Develop

Use Node from `.nvmrc` (22.23.3) and npm. Dependencies are pinned by package-lock.json.

```sh
npm ci
npx playwright install chromium
npm run dev       # http://127.0.0.1:4179/LocalDesign/
npm run check     # production build, type/skills, unit and built-browser tests
```

The editor and preview bind loopback on port 4179. Stop an existing owned dev/preview server before running another on the same port. For an isolated test server alongside another checkout, use `LOCALDESIGN_TEST_PORT=4198 npm run check`; the default remains 4179. CI starts its own built preview. Use `npm run build` then `npm run preview` for the production app. No `.env` or external service is required.

Shared controls build on shadcn base-vega/Base UI in `src/components/ui`, then compose into editor controls and screens. Choose their variants and sizes instead of styling native controls. Semantic colors live in `src/theme.css`; editor geometry stays in the components cascade layer in `src/style.css`, below component utilities. `npm run check:ui` enforces this foundation during every build. Extend the shared owner first when adding a building block.

Read [AGENTS.md](AGENTS.md) for repository-local skills. They are self-contained adaptations for development, diagnosis, review, UI design and evidence-based instruction improvement. `npm run check:skills` validates digests, response budgets, source provenance and local reference closure. Update the owning guidance and meaningful regression checks as project work reveals reusable lessons; never import document text as trusted agent instructions.
