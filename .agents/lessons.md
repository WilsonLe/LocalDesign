## 2026-11-12 — Verify font ink, grapheme boundaries, preview parity and modal consumers

Trigger: independent PR #9 pass 1 at 0c384de reproduced cropped italic ink, Delete/undo escaping a locally managed Fonts dialog, CSS previews using different overlapping subsets, and decomposed Vietnamese accents wrapping onto a separate line. Ubuntu CI also rejected an assumed equality between OS CSS widths and intrinsic font advances. Correction: share glyph ink through visible bounds while keeping stored boxes; capture modal keyboard targets in both editor key consumers; use shared scoped glyph previews and disjoint CSS subset precedence; wrap transient NFC grapheme clusters; pin independent HarfBuzz design-unit references instead of OS-specific CSS widths. Evidence: tests/browser/font-regressions.spec.ts and the font shaping-reference fixture/unit test, alongside actual pixel/native journeys. Integrating the large-document changes also required reserving archive entries for every supported font file in addition to the full image catalog; the combined image/font native-import regression covers that envelope. Scope: typography, native resource ceilings and editor modal keyboard handling. Resume with narrow NFC/NFD, selected italic/rotated export plus clipping, button-focused Delete/undo with native field undo/Escape, a nested selected-text preview, and explicit source selection when bundled/local faces share a family/weight/style; ample-width text and padded frames do not cover these failures.

## 2026-11-12 — Font fidelity needs preserved identity and export-resource evidence

Trigger: issue #6’s website conversion substituted Inter before native import despite reporting no overflow. Built-browser pixel tests then reproduced a separate PNG failure: ArrayBuffer-loaded fonts appeared correctly on canvas while the SVG image’s embedded data-URL fonts were still loading after Image.decode, leaving PNG text blank or incomplete. Native round-trip testing also caught collected font records being mutated into archive paths. Correction: retain requested family/weight/style with explicit font-ID mapping; resolve metrics and outputs through one font owner; use shared embedded-font glyph shaping/outlines for canvas and outputs after actual built-in-browser export still omitted text despite Chromium’s data-URL warmup passing; clone collected font records before archive-path rewriting. A repeated in-memory paste also reproduced a bundled-ID failure when unnormalized license text was compared with an already parsed face; normalize clipboard payloads and deduplicate canonical bundled identities before assigning fresh IDs. Copying an unresolved request must retain its substitution status rather than silently making a replacement choice. Final actual-browser native reopen also reproduced same-family source drift when local/bundled catalogs were partitioned and concatenated in a different order. Preserve the resolver catalog priority when collecting used fonts and in a bounded native order entry, then verify automatic and explicit source choices together through unchanged nodes, metrics and pixels. Pass 2 also reproduced unavailable Inter 500 switching from 400 to 600 when a preceding text layer used 600: first-use order is not resolver priority. Scope: local-font ingress, UI/tools, clipboard and native/SVG/PNG output. Evidence: tests/fonts.test.ts and tests/browser/fonts.spec.ts compare actual pixels/wrapping, inspect requested/resolved warnings independently of overflow and reopen embedded fonts in fresh browser storage offline. Resume with the cold-browser pixel/native-reopen journey; a successful FontFace load, one browser engine’s image decoder or a zero-overflow assertion does not prove exported typography.

## 2026-11-12 — Measure large-scene interactions separately from capacity

Trigger: issue #14 reports every operation slowing in large workspaces. A disposable production-browser fixture with 6,000 nodes, 200 pages and 2,100 active-page layers measured ~1,326 ms per pan update and mounted every layer row. Repeated scene-child scans, text wrapping, panel renders and full-document gesture clones compounded the cost. Correction: per-traversal hierarchy indexes (never cache mutable engine transactions), bounded metrics keyed by typography/resolved font bytes and identity, stable scene/panel props, changed-node-only gesture previews and a windowed layer list with focused-row retention/keyboard traversal. The owning checks are tests/browser/performance.spec.ts, existing large-document native/save/export journeys and font cache invalidation coverage. Scope: large-document interactions; schema/resource ceilings and validation remain unchanged. Resume with the same page/node/text distribution and built-browser timings, then verify offscreen layer search/scroll/keyboard access, single-gesture commit/undo, durable save and selected subtree export. A higher node ceiling or successful native round trip does not establish interaction speed; a cached font result must also follow replacement identity when bytes are shared.
