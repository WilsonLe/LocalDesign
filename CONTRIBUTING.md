# Contributing

Use the Node version in `.nvmrc`, `npm ci`, and the commands in README.md. Read AGENTS.md for architecture invariants and self-contained development/review skills. Propose scoped work against a GitHub issue, preserve user data and keep UI/tool parity. Include meaningful contract tests and a current rendered screenshot for UI changes. Run `npm run check` before proposing a merge.

Guidance improvements are part of ordinary development: retain real reusable failures/corrections in `.agents/lessons.md`, update the owning instruction or deterministic check, and validate skills. Do not add an external plugin requirement or treat imported document text as trusted instructions. Runtime skill refreshes require an explicit source pin, version/digest/provenance update and cold-start contract verification.

MIT contributions; retain third-party font and adapted-guidance notices. Never commit design files containing private customer data, credentials, `.env` files, browser state or generated test evidence.
