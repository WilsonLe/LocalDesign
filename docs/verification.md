# Verification scope

The repository's required release command is `npm run check`: production build (including typecheck, dependency closure/digests, skill budgets and schema-valid example tests), core/file/skill unit tests, and Playwright Chromium journeys against the production preview. The committed CI and Pages jobs run that same command.

The tests exercise atomic batch rejection, stale revisions, identical/changed retries, undo/redo, selection/view separation, hierarchy and rotated reparenting/grouping, frame layout, locks, ordering/alignment/distribution, native archive corruption/unsafe paths/expansion/missing assets/version limits, and schema-valid runtime guidance. Built-browser journeys cover manual drawing/gestures, inspector-only property patches, text, clipboard, pages/layers, persistence/reload, safe SVG/font substitution/unsafe SVG recovery, PNG/JPEG/WebP, native export and fresh-storage reopen/edit, SVG/PNG output, quota failures with backup/retry, agent/human interleaving, lifecycle retirement, unsupported WebMCP and narrow drawers/focus. Independent-review regressions verify visible group/unclipped-frame output pixels, clipped-frame/hidden controls, reference SVG transform coordinates/pixels, malformed and mismatched native raster rejection, successful >8 MB native metadata export/reopen, atomic over-budget edit rejection, Escape cancellation, and newest-save status/unload protection with a held second IndexedDB write. Current rendered specimens test text fit and export dimensions; captures are task-owned evidence outside source Git.

Two distinct agent evidence channels are maintained:

- **Controlled cold-start harness:** browser fixtures install a fake modelContext host, discover the production tools, receive only served packages/schemas, author/preview/export/reopen, test unknown versions/IDs, and retrieve guidance offline. This proves the registration/engine/packaging contracts; it does not prove a particular external browser discovers them.
- **Actual desktop built-in browser:** during implementation the browser discovered the registered site tools on the production preview and retrieved the skill catalog and complete getting-started guide through its WebMCP capability. Final authoring/export/reopen and deployed-runtime evidence are retained in the issue/PR release readback. A developer with prior source knowledge is not an independent study of future agent adherence.

The final PR/release evidence binds review, checks and deployed verification to concrete revisions. Do not infer a current production result from this source document alone. A GitHub Pages HTTP response or successful job is checked separately from manual controls, actual tool calls and native-file interoperability.

Known limits: Chromium is the automated browser; other engines/devices are not claimed. Static text metrics do not establish all script/glyph shaping; bundled Inter supports Latin/extended Latin/Vietnamese only. Safe SVG import is intentionally narrow and not a general SVG export round trip. There is no multiplayer merge resolution; each browser tab has its own working state. IndexedDB compares the last observed saved copy transactionally and rejects conflicting writes from another tab, preserving both the existing saved data and the unsaved active view. Export a backup or use Save a copy to recover. History/receipts are memory-only; browser storage is not a portable backup. v0.1 is a small design editor, not complete Figma compatibility.
