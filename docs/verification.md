# Verification scope

The repository's required release command is `npm run check`: production build (including typecheck, dependency closure/digests, skill budgets and schema-valid example tests), core/file/skill unit tests, and Playwright Chromium journeys against the production preview. The committed CI and Pages jobs run that same command.

The tests exercise atomic batch rejection, stale revisions, identical/changed retries, undo/redo, selection/view separation, hierarchy and rotated reparenting/grouping, frame layout, locks, ordering/alignment/distribution, native archive corruption/unsafe paths/expansion/missing assets/version limits, and schema-valid runtime guidance. Built-browser journeys cover manual drawing/gestures, inspector-driven horizontal/vertical frame layout with gap/padding/alignment and shared undo/redo, inspector-only property patches, text, clipboard, pages/layers, persistence/reload, safe SVG/font substitution/unsafe SVG recovery, PNG/JPEG/WebP, native export and fresh-storage reopen/edit, SVG/PNG output, quota failures with backup/retry, agent/human interleaving, lifecycle retirement, unsupported WebMCP and narrow drawers/focus. Independent-review regressions verify visible group/unclipped-frame output pixels, clipped-frame/hidden controls, reference SVG transform coordinates/pixels, malformed and mismatched native raster rejection, successful >8 MB native metadata export/reopen, atomic over-budget edit rejection, Escape cancellation, newest-save status/unload protection with a held second IndexedDB write, delayed image decoding across page retirement/caller cancellation, cancelled workspace switching, and byte-signature/MIME matching across tool/clipboard/native round trips. Current rendered specimens test text fit and export dimensions; captures are task-owned evidence outside source Git.

Two distinct agent evidence channels are maintained:

- **Controlled cold-start harness:** browser fixtures install a fake modelContext host, discover the production tools, receive only served packages/schemas, author/preview/export/reopen, test unknown versions/IDs, and retrieve guidance offline. This proves the registration/engine/packaging contracts; it does not prove a particular external browser discovers them.
- **Actual desktop built-in browser:** during implementation the browser discovered the registered site tools on the production preview and retrieved the skill catalog and complete getting-started guide through its WebMCP capability. Final authoring/export/reopen and deployed-runtime evidence are retained in the issue/PR release readback. A developer with prior source knowledge is not an independent study of future agent adherence.

The final PR/release evidence binds review, checks and deployed verification to concrete revisions. Do not infer a current production result from this source document alone. A GitHub Pages HTTP response or successful job is checked separately from manual controls, actual tool calls and native-file interoperability.

Known limits: Chromium is the automated browser; other engines/devices are not claimed. Static text metrics do not establish all script/glyph shaping; bundled sans/serif/monospace faces cover Latin/extended Latin/Vietnamese; imported font coverage is checked from its character map. Safe SVG import is intentionally narrow and not a general SVG export round trip. There is no multiplayer merge resolution; each browser tab has its own working state. IndexedDB compares the last observed saved copy transactionally and rejects conflicting writes from another tab, preserving both the existing saved data and the unsaved active view. Export a backup or use Save a copy to recover. History/receipts are memory-only; browser storage is not a portable backup. LocalDesign is a small design editor, not complete Figma compatibility.

Font regressions use licensed static OTF/TTF fixtures plus pinned WOFF/WOFF2 subsets. They verify real family/weight/style/coverage, embedding restrictions, corrupt/oversized/expanding input, atomic guarded history, native v1 compatibility, explicit missing-font mapping, glyph warnings independent of overflow, wide/narrow manual controls, cancellation after decoding, and font-bearing clipboard transfers. The source selector also chooses an imported face when a native working copy retains a bundled face with the same family/weight/style. A native round trip preserves both that explicit choice and an automatic bundled choice in the same document, comparing nodes, metrics and PNG pixels; malformed order metadata rejects before replacement. Independent-review regressions cover selected italic/diacritic ink and clipping, button-focused dialog shortcuts with native input undo, shared-renderer preview glyphs/subset precedence, and narrow NFC/NFD wrapping/pixels. The built-browser specimen compares canvas pixels against embedded-font SVG/PNG/preview and checks identical wrapping/metrics/PNG after fresh-storage offline native reopen. These comparisons establish the tested faces/text in Chromium, not exact system-font equivalence for the original website.

Actual built-in-browser verification additionally discovered and executed the page tools, selected a replacement through the UI, changed/undid style after native reopen, and inspected exported pixels. Its image decoder produced blank text with embedded SVG web fonts even after Chromium’s data-URL warmup passed. The shared outline renderer removes that dependency. Current candidate screenshots/artifacts remain outside Git; hosted CI, merge and deployed evidence are separate.

The original wilsonle.me v1 archive was also opened in a disposable Chromium context: six pages, 1,028 layers, 550 text layers already declared as Inter. Its nine embedded Inter subsets match the current pinned bytes. Six representative home headings and four labels were restored from the observed CSS family stacks and explicitly mapped to portable substitutes while preserving text, position, boxes, size, tracking and line height. The source archive checksum stayed unchanged. Some fitted legacy headings overflow after mapping; no silent fitting was applied, and exact Iowan Old Style / SFMono-Regular fidelity is not claimed. The legacy conversion had already discarded font requests, so those cannot be recovered automatically from that file.

Font advance references are generated independently with HarfBuzz and pinned by font-file SHA-256 in tests/fixtures/fonts/shaping-reference.json. macOS and Linux browser CSS measurements differ because they are a separate rendering path; the product uses unhinted embedded-font shaping/outlines. CI therefore asserts the independent design-unit references and actual exported pixels rather than requiring OS CSS metrics to be identical.

Large-project coverage (issue #7) imports a synthetic 17,716-node/206-page/656-asset archive into the engine, edits a selection beyond the old node cap and verifies undo. Built-browser coverage opens, edits, persists/reloads and exports/reopens a 4,201-node/206-page/257-asset scene, then rejects an over-limit replacement without losing the working copy. A combined native-import regression retains the full 10,000-image catalog plus 48 three-file local fonts, so the archive entry budget covers both resource kinds. Count and byte ceilings remain finite and share one owner in `src/core/limits.ts`; image, path, expansion, hierarchy and schema safeguards remain enforced. A separate task-owned Silebot archive supplies actual built-in-browser evidence; user designs are not committed as test fixtures.

Use `LOCALDESIGN_TEST_PORT=4198 npm run check` for an isolated test listener when the default port belongs to another checkout. The override is validated as an integer port and applies to both the preview command and test base URL.

Independent PR #8 review reproduced a JavaScript argument-stack failure in bounds for 40,000 visible rectangles below the new ceilings. Bounds now reduces corner extrema iteratively; a regression validates and fits that scene without spreading coordinate arrays. Existing rotated/stroked/group/clipped export journeys retain the consumer checks. The large-scene ceiling is not a guarantee of device performance or unlimited per-gesture command counts.

Layer-navigation coverage (issue #10) uses a synthetic tall Hero/Selected work/Get in touch/Footer profile and a distant rotated nested workspace at 1440, 1000 and 390 px. It checks clear canvas bounds against the floating controls, stable repeated activation, Shift/keyboard selection, drawer dismissal/focus, hidden/locked controls, group and frame clipping bounds, and unchanged nodes/revision/history. Panel display sorting is checked separately from scene paint/auto-layout order; served cold-start packages include the organization/finishing guidance. These fixtures do not establish future agents' adherence to the guidance.
