# 0003 — Portable fonts and preserved typography

Status: accepted for issue #6. Supersedes ADR 0001’s Inter-only font scope and schema-v1 export decision; the browser-local architecture and safe import boundaries remain.

Scene schema v2 adds a document font catalog and text fontStyle/fontId. fontFamily, fontWeight and fontStyle describe the requested face; nullable fontId explicitly maps it to a catalog face without rewriting the request, text, size, tracking, line height or box. Unavailable families, style/weight pairs, IDs and glyphs remain editable and produce separate, actionable requested/resolved warnings. Overflow does not establish fidelity. Deliberately selecting a family/style changes the request; choosing Replacement preserves it.

The licensed bundled catalog is Inter and Source Serif 4 at 400/600/700 normal/italic, plus IBM Plex Mono at 400/700 normal/italic, with Latin/extended Latin/Vietnamese subsets. Only real files are offered; browser synthesis is disabled. The local-font boundary accepts static TTF/OTF/WOFF/WOFF2 with explicit redistribution permission and a license/provenance notice. Format/table expansion, intrinsic family/weight/style, character map, embedding restrictions and browser decoding validate before guarded commit/replacement. Collections and variable fonts are rejected. No system font scanning, paid-font download, external URL fetch, host path, design upload or automatic redistribution occurs.

`src/fonts` owns font schemas, intrinsic parsing and content identity; commands/engine remain the only document mutation path. `src/render/fonts.ts` resolves requested/mapped faces. `src/render/glyphs.ts` shapes the actual embedded bytes and shares glyph positions/advances with text metrics and the SVG scene renderer. Scene-level path definitions deduplicate glyphs, with internal use references for canvas/SVG/PNG. Text stays editable in the native scene; SVG text is outlined and retains accessible text/font identity plus embedded font bytes/notices. FontFace decoding is awaited for validation. Family previews use the same scoped glyph definitions as the document; CSS subset ranges are disjoint with the same first-file precedence as shaping. Logical text boxes remain unchanged, while shared glyph ink bounds expand visible fit/export bounds through world transforms and respect clipping. Wrapping uses transient NFC grapheme clusters without rewriting stored text. Dialog focus captures all canvas shortcuts while retaining native field undo and Escape. Missing glyphs show placeholders and actionable warnings; static color/bitmap fonts are rejected.

This removes an observed consumer difference: Chromium could finish Image.decode before embedded web fonts, leaving PNG text incomplete. Loading the exact SVG data-URL FontFace fixed Chromium, but actual built-in-browser export still produced blank text. A common outline renderer avoids SVG-image font loading entirely. Glyph tables/path complexity and bounded parser/outline/run caches are validated/limited before rendering; Unicode canonical composition for shaping does not rewrite the stored text.

Native v2 catalogs embed document fonts plus used bundled faces, their full notices and provenance, with safe archive paths. Local face metadata lives in document.json; bundled metadata lives in fonts/catalog.json within the 1 MB reserve, so adding a bundled face cannot overflow an otherwise valid document.json. Bundled byte/license fingerprints bind the claimed catalog source; altered faces must enter as local licensed fonts. Imported faces are decoded before any working-copy replacement. Native v1 Inter-only files and saved working copies migrate to v2 with normal style/no replacement/empty font catalog; older editors reject v2 exports. There is no destructive storage migration. Copy/paste carries the actual selected font bytes/assignments across local documents. Native export clones collected records before replacing data with archive paths, preserving the active document and history.

Budgets: 4 MB per font file, 16 MB expanded font tables, 48 local faces / 12 MB per document, at most 66 catalog faces including the bundled reserve. Metadata stays within 24 MB; metadata/images/local fonts share 30 MB plus a 1 MB bundled-font reserve. Native archives remain at most 32 MB compressed / 80 MB expanded, at most 300 safe entries. Embedded bytes, metadata and browser validation must agree; a signature or reported overflow alone is insufficient.

Evidence: font metadata/format/license/budget/atomic-history and v1/v2 archive regressions in tests/fonts.test.ts; built-browser UI/tool assignment, missing requests/glyphs, cancellation, real canvas/SVG/PNG pixels and fresh-storage offline native reopen in tests/browser/fonts.spec.ts. A representative wilsonle.me heading/label/body comparison uses its observed system stacks; Source Serif 4 / IBM Plex Mono are explicit portable replacements, not claimed exact matches for Iowan Old Style / SFMono-Regular. The licensed Inter body face can match when the requested weight is available. No existing user design is modified for verification.

Rollback: revert the feature through a reviewed PR. Keep v2 native backups and browser working copies; the old editor cannot open them. Do not clear storage or downgrade saved designs silently.
